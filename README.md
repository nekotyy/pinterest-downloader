> **Первый запуск:** архив содержит и программу, и расширение. Программу нужно запустить в Windows, а расширение — один раз подключить в браузере. Устанавливать .NET или среду разработки не нужно. В архиве также есть простая инструкция `ИНСТРУКЦИЯ.txt`.

## Что умеет

- **Находит открытые пины.** Открой фотографии в отдельных вкладках Pinterest — расширение передаст их приложению.
- **Показывает карточки.** Просматривай найденные изображения и выбирай, что сохранить. Повторно открытый пин появится один раз.
- **Сохраняет выбранное.** Укажи папку и скачай нужные изображения; приложение запомнит путь.
- **Не закрывает вкладки и не перезаписывает файлы.** Если файл с таким именем уже есть в папке, приложение сообщит об этом.
- **Показывает состояние загрузки.** У каждой карточки отображается результат: сохранено, файл уже существует или причина ошибки.

## Установка

### 1. Скачай и распакуй архив

1. Открой [страницу последнего релиза](https://github.com/nekotyy/pinterest-download/releases/latest).
2. В разделе **Assets** выбери **PinterestDownload-Windows.zip** для Windows или **PinterestDownload-Linux.tar.gz** для Linux. Если список свёрнут, сначала раскрой его.
3. После скачивания извлеки весь архив: в Windows через **«Извлечь всё…»**, в Linux — через архиватор или командой `tar -xzf PinterestDownload-Linux.tar.gz`.
4. Выбери постоянную папку и извлеки туда содержимое.

Внутри будут примерно такие файлы:

```text
PinterestDownload-Windows/
├── app/
│   └── PinterestDownload.exe  ← в Windows; в Linux — PinterestDownload
├── extension/
│   ├── manifest.json          ← расширение для браузера
│   └── background.js
├── extension-firefox/         ← расширение для Firefox
├── ИНСТРУКЦИЯ.txt             ← краткая инструкция
├── docs/                      ← изображения для инструкции
└── README.md
```

Папку `extension` после подключения лучше не перемещать: Браузер загружает расширение из неё. Если переместишь весь комплект, удали старую запись расширения и подключи папку из нового расположения заново.

### 2. Подключи расширение в браузере

#### Chrome, Edge и другие браузеры на Chromium

1. Открой страницу расширений браузера: в Chrome — `chrome://extensions`, в Edge — `edge://extensions`. В других браузерах открой раздел «Расширения» в меню.
2. Включи **«Режим разработчика» / Developer mode**.
3. Нажми **«Загрузить распакованное расширение» / Load unpacked**.
4. Выбери именно папку **`extension`** из распакованного архива — ту, в которой находится `manifest.json`.
5. Убедись, что расширение **Pinterest Download — вкладки** включено.
6. Для удобства закрепи его значок на панели браузера через меню расширений, если такая возможность доступна в твоём браузере.

Расширению нужен доступ к вкладкам, страницам Pinterest и локальному приложению, чтобы находить пины и передавать их в программу.

#### Firefox

1. Открой `about:debugging#/runtime/this-firefox` и нажми «Загрузить временное дополнение».
2. Выбери `manifest.json` в папке `extension-firefox`.
3. После перезапуска Firefox расширение нужно загрузить снова: постоянная установка требует подписи Mozilla.

Совместимость с другими браузерами зависит от поддержки их API расширений и не гарантируется.
Если расширение установлено в нескольких браузерах или профилях одновременно, каждый из них передаёт свой список и заменяет предыдущий; используй один профиль за раз.

### 3. Запусти приложение

1. В Windows открой папку `app` и запусти **PinterestDownload.exe**.
2. В Linux запусти **app/PinterestDownload**. При необходимости разреши запуск: `chmod +x app/PinterestDownload`.
3. Оставь приложение открытым и переходи к выбору изображений. На Linux нужны графическое окружение и системные библиотеки; в Wayland может понадобиться XWayland.

## Как пользоваться

1. В браузере открой нужные изображения Pinterest **каждое в отдельной вкладке**. Адрес должен вести на пин, например `https://ru.pinterest.com/pin/123456789/`.
2. Вернись в окно Pinterest Download. Расширение обновляет список автоматически; это может занять до 30 секунд. Чтобы запросить обновление сразу, нажми его значок на панели браузера.
3. В галерее сними галочки с ненужных карточек или воспользуйся кнопкой выбора всех пинов.
4. Нажми **«Изменить папку»**, если хочешь сохранить изображения в другом месте. По умолчанию используется системная папка изображений Windows.
5. Нажми **«Скачать выбранные»** и дождись результата под каждой карточкой.
6. Чтобы вернуться к странице изображения, нажми **«Открыть пин»** на карточке.

Файлы сохраняются под именами вида `pinterest_123456789.jpg`; расширение зависит от формата полученного изображения. Наличие файла с тем же именем не приведёт к его перезаписи.

## Если что-то не работает

<details>
<summary><strong>В приложении нет открытых пинов</strong></summary>

- Проверь, что программа запущена, а расширение включено на странице расширений браузера.
- Убедись, что открыты именно страницы пинов с `/pin/` в адресе, а не только результаты поиска или доска.
- Дождись полной загрузки вкладок и нажми значок расширения. При необходимости обнови страницы пинов.
- Проверь, что расширение установлено в том профиле браузера, в котором открыты вкладки.

</details>

<details>
<summary><strong>На значке расширения появился восклицательный знак</strong></summary>

Расширению не удалось передать список локальному приложению. Запусти приложение и нажми значок расширения ещё раз. Если оно уже открыто, проверь, не запущена ли вторая копия программы и не занят ли локальный порт `17849` другой программой.

</details>

<details>
<summary><strong>Нет предпросмотра или изображение не скачивается</strong></summary>

Дождись загрузки страницы пина, обнови её и снова нажми значок расширения. Некоторые страницы могут не предоставить подходящий адрес изображения; также возможны ошибки сети или ограничения со стороны Pinterest. Текст ошибки появится на карточке после попытки скачивания.

</details>

<details>
<summary><strong>Приложение не открывается</strong></summary>

Проверь, что архив полностью распакован и скачана версия для твоей системы. В Linux проверь право на запуск файла и наличие графической среды. Если приложение сообщает об ошибке запуска, убедись, что другая копия не открыта.

</details>

<details>
<summary><strong>Не вижу кнопку скачивания на GitHub</strong></summary>

Войди в GitHub под аккаунтом с доступом к приватному репозиторию, открой [последний релиз](https://github.com/nekotyy/pinterest-download/releases/latest) и раскрой раздел **Assets**. Нужный файл — **PinterestDownload-Windows.zip**.

</details>

## Как это работает

Расширение ищет открытые вкладки Pinterest и считывает доступный на каждой странице адрес изображения. Список передаётся приложению через локальный адрес `127.0.0.1:17849`; отдельный сервер не нужен. Изображения загружаются с адресов `pinimg.com`. Путь к папке сохраняется локально в настройках пользователя.

Приложение не запрашивает логин и пароль Pinterest. Расширению выданы разрешения на доступ к вкладкам и страницам Pinterest; в приложении проверяются адреса пинов и изображений. Для загрузки по-прежнему необходимо интернет-соединение.

> Доступность и качество изображения зависят от данных, которые возвращает открытая страница. Приложение не гарантирует оригинальное разрешение и не поддерживает отдельную загрузку видео. Учитывай права авторов и [условия Pinterest](https://policy.pinterest.com/en/terms-of-service).

## Разработка

Для обычного использования этот раздел не нужен. Для запуска из исходников на Windows или Linux потребуется .NET 8 SDK:

```powershell
dotnet restore
dotnet run
```

Для проверки расширения нужен Node.js:

```powershell
node tests/extension.test.js
```

Самодостаточная сборка для Windows x64 (для Linux замени `win-x64` на `linux-x64`):

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

GitHub Actions также собирает архив при отправке изменений; результаты доступны на странице [Actions](https://github.com/nekotyy/pinterest-download/actions). Установка расширений из исходников выполняется так же, как описано выше.
