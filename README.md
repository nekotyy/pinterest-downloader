# Pinterest Download

Приложение Windows для просмотра и сохранения изображений из открытых вкладок Pinterest в Chromium-браузере.

## Установка

1. Скачайте `PinterestDownload-Windows.zip` из артефактов последнего успешного запуска **Actions → Build Windows app** на GitHub и распакуйте архив целиком в постоянную папку.
2. В Helium откройте страницу расширений (`chrome://extensions`), включите режим разработчика и выберите **Загрузить распакованное расширение**. Укажите папку `extension` из архива. Папку после этого не перемещайте.
3. Запустите `app/PinterestDownload.exe`, откройте пины во вкладках и дождитесь обновления (обычно до 30 секунд). Для немедленного обновления нажмите значок расширения.
4. Выберите карточки и папку, нажмите «Скачать выбранные».

Приложение самодостаточное: .NET устанавливать не нужно. Требуется установленный [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). Приложение и расширение обмениваются данными только через localhost. Вкладки не закрываются.

Приложение получает адрес изображения из уже открытой страницы; для некоторых пинов Pinterest может не предоставить изображение или доступное качество может отличаться от оригинала. Авторизация и обход ограничений Pinterest не реализованы. Используйте материалы с учётом прав авторов и условий Pinterest.

## Разработка

Нужен .NET 8 SDK и Windows: `dotnet run`. Сборка: `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`.
