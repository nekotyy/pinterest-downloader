# Pinterest Download

![Баннер Pinterest Download](docs/banner.png)

Приложение для Windows и Linux сохраняет изображения из открытых вкладок Pinterest. Интерфейс работает на Avalonia. Расширение передаёт список вкладок через локальное соединение.

[Скачать последнюю версию](https://github.com/nekotyy/pinterest-download/releases/latest) | [Сообщить об ошибке](https://github.com/nekotyy/pinterest-download/issues/new/choose) | [Обсуждения](https://github.com/nekotyy/pinterest-download/discussions)

## Возможности

- Список пинов из одного или нескольких браузеров и профилей.
- Статус подключения расширений, обработки вкладок и загрузки файлов.
- Предпросмотр, выбор пинов и папки для сохранения.
- Предупреждение о ранее скачанном пине и повторное сохранение под новым именем.
- Светлая и тёмная темы в соответствии с настройками системы.

## Установка

1. Скачай архив для своей системы со [страницы релизов](https://github.com/nekotyy/pinterest-download/releases/latest). Для доступа к приватному репозиторию нужно войти в GitHub.
2. Распакуй архив целиком в постоянную папку.
3. В Windows запусти `app/PinterestDownload.exe`. В Linux запусти `app/PinterestDownload`; при необходимости разреши выполнение командой `chmod +x app/PinterestDownload`. В Linux нужна графическая среда; в Wayland может потребоваться XWayland.
4. Подключи расширение, как описано ниже. Краткая инструкция также находится в файле `ИНСТРУКЦИЯ.txt` внутри архива.

.NET SDK и WebView2 для запуска готового приложения не нужны.

### Chrome, Edge и другие браузеры на Chromium

1. Открой страницу расширений браузера: `chrome://extensions` в Chrome или `edge://extensions` в Edge. В других браузерах используй раздел расширений в меню.
2. Включи режим разработчика и выбери загрузку распакованного расширения.
3. Укажи папку `extension` из архива. Не перемещай её после установки. При обновлении удали старое расширение и подключи папку из нового архива.
4. Открой расширение на панели браузера. При необходимости выбери название браузера и нажми «Обновить вкладки».

Разные браузеры на Chromium могут ограничивать установку распакованных расширений в своих настройках.

### Firefox

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми «Загрузить временное дополнение» и выбери файл `extension-firefox/manifest.json` из архива.
3. После перезапуска Firefox повтори установку. Постоянная установка требует подписи Mozilla.

Совместимость с другими браузерами зависит от поддержки API расширений и не гарантируется.

## Использование

Открой нужные пины в отдельных вкладках, например `https://ru.pinterest.com/pin/123456789/`. Запусти приложение и проверь статус подключения. Выбери браузер или все источники, затем выбери карточки и папку. Нажми «Скачать выбранные».

Расширение обрабатывает вкладки параллельно с ограничением нагрузки. Приложение показывает карточки страницами по 100. Браузер может выгрузить неактивную вкладку из памяти. Чтобы запросить её повторную загрузку, нажми «Загрузить выгруженные вкладки» и оставь окно расширения открытым до окончания операции. Если браузер отклонит запрос, открой вкладку вручную.

Ранее сохранённые пины определяются по идентификатору. История хранится локально и проверяет, существует ли файл. Проверка совпадения содержимого разных пинов не выполняется. Чтобы сохранить копию, включи «Скачивать повторно».

## Решение проблем

- **Нет подключения.** Проверь, что приложение запущено, расширение включено, а порт `17849` свободен. Открой расширение и нажми «Обновить вкладки».
- **Пин не появился.** Проверь, что открыта страница с `/pin/` в адресе и расширение установлено в нужном профиле браузера.
- **Нет изображения.** Открой вкладку, дождись загрузки страницы и обнови список. Pinterest может не предоставить изображение; его доступное качество не обязательно совпадает с оригиналом.
- **Приложение не запускается.** Убедись, что архив распакован полностью и соответствует системе. В Linux проверь право на выполнение файла и графическую среду.

## Приватность и ограничения

Расширение читает адреса открытых вкладок и данные страниц Pinterest. Приложение получает их через `127.0.0.1:17849`; изображения загружаются с `pinimg.com`. Пароль Pinterest не запрашивается. Путь к папке и история загрузок хранятся локально.

Приложение не гарантирует исходное разрешение и не поддерживает отдельное скачивание видео. Используй материалы с учётом прав авторов и [условий Pinterest](https://policy.pinterest.com/en/terms-of-service).

## Разработка

Для запуска из исходников нужны .NET 8 SDK и Node.js для проверки расширения:

```powershell
dotnet run
node tests/extension.test.js
dotnet run --project tests/HistoryChecks/HistoryChecks.csproj
```

Самодостаточная сборка:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Для Linux используй `linux-x64`. GitHub Actions проверяет запуск и собирает архивы для обеих систем.
