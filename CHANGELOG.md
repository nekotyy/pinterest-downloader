# История изменений

## 0.4.0

- Добавлены индикатор прогресса и отмена скачивания.
- Добавлено закрытие вкладок сохранённых пинов для выбранного браузера.
- В расширении появились настройки частоты синхронизации и обработки вкладок.
- Добавлены поиск по названию или ID и фильтр сохранённых изображений.
- Обновлены название проекта, баннер и документация.
- Добавлены лицензия MIT и дополнительные проверки загрузок и команд расширения.

## 0.3.0

- Добавлены состояние браузеров, история скачиваний и повторное сохранение.
- Добавлена обработка больших списков и загрузка выгруженных вкладок.
- Добавлены темы интерфейса и значки приложения и расширения.

## 0.2.0

- Интерфейс переведён на Avalonia для Windows и Linux.
- Добавлено временное расширение для Firefox.

## 0.1.0

- Первая версия приложения для Windows и расширения для Chromium.
